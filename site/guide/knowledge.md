# Knowledge 知识库

基于真实医学教材的结构化知识检索。正文来自教材原文片段，并标注页码与出处。

## 核心能力

- **目录浏览**：篇 → 章 → 节 → 细单元，按系统与疾病组织
- **知识点详情**：普通条目展示裁切后的原文要点；治疗/用药等高风险段落以**教材原文证据**展示，不强行总结成结论
- **全文搜索**：PostgreSQL FTS，中文分词（云端数据路径）
- **语义检索**：pgvector 向量搜索（云端数据路径）
- **费曼复述**：用自己的话复述，系统对比原文标注理解偏差
