# 下载安装

## Android

### 通过 APK 安装

1. 下载最新的 APK 文件
2. 打开文件管理器，找到下载的 APK
3. 点击安装（首次安装需允许「未知来源」）
4. 安装完成后打开 MedLearn

> 当前版本：**0.1.0**（内测）

### 系统要求

- Android 9.0 (API 28) 及以上
- ARM64-v8a 架构

## iOS

iOS 版本即将推出。

## 权限说明

| 权限 | 用途 |
|------|------|
| 网络访问 | 云同步、知识库更新 |
| 存储（可选） | 缓存知识数据供离线使用 |

MedLearn **不会**请求：通讯录、短信、相机、麦克风、位置信息。

装好了？去 [快速上手](/guide/getting-started) 开始使用。
