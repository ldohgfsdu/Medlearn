# 快速上手

恭喜。你的临床思维训练之路，从这里开始。给我 3 分钟，带你上手。

## 1. 安装

去 [下载安装](/guide/installation) 页面，选择你的设备，装好 MedLearn。

## 2. 认识首页

打开 MedLearn，你会看到两个入口：

- **知识库** 📚 — 结构化医学知识，搜索、浏览、学习
- **病例模拟** 🧠 — 从主诉出发的临床推理训练

两个入口**完全独立**。没有强制顺序。

## 3. 你的第一次知识检索

1. 点击「知识库」
2. 搜索框输入你想查的疾病或症状，比如「肺炎」
3. 点击结果，查看结构化的知识卡片：概述、病因、临床表现、诊断、治疗
4. 试试「费曼复述」：用自己的话复述，系统帮你发现理解偏差。

## 4. 你的第一次病例模拟

1. 点击「病例模拟」
2. 选择一个主诉，比如「发热 3 天」
3. 按真实临床流程操作：问诊 → 查体 → 检查 → 诊断 → 处理
4. 提交后查看评分反馈：✅ 做对了什么 / ⚠️ 遗漏了什么 / 💡 下一步该练什么

## 进阶提示

- 做错的题会收录到错题本，可一键跳转回教材原文
- 病例训练与知识库可自由切换，没有强制顺序
- 登录并打开云同步后，病例记录与费曼复述可跨设备衔接
