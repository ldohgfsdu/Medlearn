# 病例模拟 (Case Simulator)

病例模拟是 MedLearn 的核心训练模块——在安全的环境中反复练习临床推理。

## 设计理念

> 不是在考你。是在训练你。

目标是帮你建立**可迁移的临床推理能力**——培养「给一个主诉，我知道该怎么想」的思维习惯。

## 训练流程

**第一步：选择主诉** — 从列表中选择，如「发热 3 天」「胸痛 2 小时」

**第二步：信息收集** — 通过问诊、查体、检查与患者对话收集线索

**第三步：诊断与处理** — 提交主要诊断、鉴别诊断、支持证据与治疗方案

**第四步：评分反馈** — 按诊断准确性、鉴别诊断、证据运用、治疗方案四个维度评估，详见 [评分与反馈](/features/scoring)

## 反馈特色

不只是告诉你对错，而是告诉你**为什么**和**接下来怎么办**。系统追踪多轮训练，找出模式性薄弱点，针对性推荐练习。

病例模拟和知识库不是前序-后序关系。先查再练、直接练、练完再查，三种模式都支持。
