# 知识库 (Knowledge)

知识库是 MedLearn 的知识底座——结构化、可搜索、每条可追溯到教材原文。

## 知识从哪来

MedLearn 的知识来自**权威医学教材**。管线从 PDF 提取连续原文片段（evidence），在严格规则下整理为可浏览条目；**不能绑定原文的内容不会当成普通结论发布**。

这意味着：

- 普通知识点：正文是教材原文的裁切片段，可展开查看更完整的 evidence
- 治疗、用药、剂量等：多以 **evidence-only** 形式展示**整段原文**，不替你总结成「学习卡片结论」
- 自动质检保证「展示文字能在书里找到」，**不等于**临床专家已逐条审校发布

## 如何浏览知识

### 目录浏览

按**篇 → 章 → 节**组织；大章会进一步拆成细单元（例如 `第二节 细菌性肺炎 · 治疗`），方便定位和错题跳转。

示例路径：呼吸系统 → 肺部感染性疾病 → 细菌性肺炎 → 治疗。

### 全文搜索

知识搜索（`/search`）查询 Supabase `knowledge_nodes`，支持疾病名称、别名与子章节的模糊匹配（`ilike`），需联网。

教材目录页（`/map`）另有本地目录过滤，可离线按章节名浏览内科学 bundle。

### 知识点详情页

教材学习路径：`/textbook/[章节]/unit/[单元]`。

| 展示类型 | 你看到什么 |
|---------|-----------|
| **普通条**（约九成） | 标题 + 正文要点 + 页码；正文与原文不一致时可「展开原文」 |
| **仅原文条**（约一成） | 直接展示教材原文 + 页码，不额外总结 |
| **错题定位** | 从错题进入时，顶部显示定位卡与对应页码原文 |

## 知识卡片结构

目录与分组会按教材结构推断，常见模块包括：

| 模块 | 内容 |
|------|------|
| **概述** | 定义、流行病学、关键特征 |
| **病因** | 病原体、危险因素、发病机制 |
| **临床表现** | 症状、体征、自然病程 |
| **诊断** | 诊断标准、鉴别诊断、推荐检查 |
| **治疗** | 多为原文证据展示，不强行组织成结论 |
| **预后** | 转归、并发症、预防 |

## 费曼复述

> 如果你不能用简单的话说清楚，那你还没真懂。—— 费曼

读完一段知识后，用自己的话复述。系统对比原始知识，标记遗漏点和理解偏差。

## 概念关联

每个知识卡片底部有关联链接：相关疾病、检查、药物、病例。点击跳转，建立知识网络。
