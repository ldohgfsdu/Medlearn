# 云同步

学习进度在多台设备间无缝流转。

## 同步内容

登录后同步到 Supabase 的数据包括：

- 病例会话与消息（`case_sessions`、`case_messages`）
- 训练行为埋点（`case_events`）
- 费曼复述记录（`feynman_records`）
- 用户资料（`user_profiles`）

错题本、教材 bundle 等数据主要保存在本地；联网后相关学习记录会上传同步。

## 离线模式

没有网络时照常使用，数据本地缓存，联网后自动上传同步。核心知识库完全离线可用。

## 数据隐私

你的学习数据只有你自己能看到。不用于训练 AI，不分享给第三方。
