# 评分与反馈

MedLearn 的评分系统帮你**发现认知盲区**。

## 评分维度

完成病例提交后，评分报告按四个维度展示（与 App 内 `score` 页一致）：

| 维度 | 评估内容 |
|------|---------|
| 诊断准确性 | 主要诊断是否正确，表述是否精确 |
| 鉴别诊断 | 是否列出有效鉴别及推理质量 |
| 证据运用 | 提交的关键证据是否覆盖病例要求 |
| 治疗方案 | 是否覆盖关键处置，是否避开危险方案 |

评分逻辑在服务端 Edge Function（`case-submit` + `_shared/case-scoring.ts`）执行，客户端只展示结果。

## 反馈层次

**即时反馈** — 完成病例后立即看到各维度得分、诊断/治疗分析与遗漏项

**趋势分析** — 跨题追踪诊断准确率等统计（个人页）

**靶向建议** — 结合薄弱点推荐后续练习与复习

评分是私人的自我提升工具。没有排行榜，没有社交比较。
