# 搜索与目录

MedLearn 提供两种互补的检索方式。

## 知识搜索（`/search`）

查询 Supabase `knowledge_nodes`，支持标题与子章节的模糊匹配（`ilike`），需联网登录。

| 搜索类型 | 示例 | 说明 |
|---------|------|------|
| 疾病名称 | `肺炎` | 匹配节点标题 |
| 别名/子章节 | `社区获得性肺炎` | 匹配 `sub_chapter` |
| 缩写 | `COPD`, `CAP` | 作为普通文本匹配 |

结果跳转到与知识地图相同的详情页，保持阅读体验一致。

## 教材目录（`/map`）

按**篇 → 章 → 节**组织，读取本地内科学 bundle，可离线浏览；顶部搜索框用于过滤目录名称（如「呼吸系统」「肺部感染」）。

**搜索 vs 目录：** 知道查什么→用知识搜索；想按教材结构浏览→用目录；不确定关键词→先用目录定位章节，再用搜索查具体条目。
