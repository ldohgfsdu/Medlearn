# 设计规范

设计系统实现在 `constants/theme.ts`，基于 PRD 临床编辑风格。

## 原则

1. **专业可信** — clinical green 主色，纸质感中性背景
2. **高效专注** — 最小化视觉噪音，证据与正文层级清晰
3. **移动优先** — 触控区域充足，适配碎片时间阅读

## 颜色

| Token | 值 | 说明 |
|-------|-----|------|
| `primary[500]` | `#1F7563` | 主色 |
| `primary[700]` | `#124B40` | 主色深、按钮常用 |
| `ink` | `#17332C` | 标题/品牌深色 |
| `success` | `#2D8A68` | 正向反馈 |
| `warning` | `#C6832B` | 注意 |
| `error` | `#C6534A` | 错误/危险 |
| `info` | `#347C91` | 信息提示 |
| `accent` | `#E27A57` | 强调点缀 |

文档站首页渐变（`site/index.md`）仅用于营销页，App UI 以 `theme.ts` 为准。
