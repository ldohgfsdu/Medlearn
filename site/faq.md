# 常见问题 FAQ

## 使用相关

**MedLearn 需要联网吗？** 核心功能完全离线可用。云同步需要网络。

**数据安全吗？** 存储在 Supabase 加密传输，不用于训练 AI，不分享给第三方。

**支持哪些设备？** 目前支持 Android 9.0+，iOS 正在开发中。

**病例是真实病例吗？** 基于典型临床表现设计，不对应特定患者真实信息。

## 学习相关

**知识可靠吗？** 来自权威教材原文，带页码出处；经自动提取与绑定质检。治疗、用药等多以原文证据展示，**不等于**临床专家已逐条审校为「可发布医学结论」。

**为什么有些治疗内容只有原文、没有总结？** 故意设计。剂量、方案、禁忌等高风险段落只展示教材原文，避免未审校内容被当成学习结论。

**费曼复述怎么用？** 用自己的话复述，系统对比标注遗漏和理解偏差。

**可以先查知识再模拟吗？** 可以。两者完全独立，自由切换。

**做错了会影响什么？** 什么也不影响。评分是私人工具，没有排行榜。

**Knowledge 和 Case Simulator 必须按顺序吗？** 不需要，两者完全独立。

## 技术相关

**MedLearn 用 AI 吗？** 辅助费曼复述分析、薄弱点定位、病例评分；教材知识正文来自 PDF 提取与规则校验，不用于「生成医学知识」。

**可以导出数据吗？** 即将支持。

**AI 建议可靠吗？** 仅用于教育，经过安全过滤，不替代医学审查。

## 开发者 / 本地运行

**启动 OOM？** Windows + Node 24 + Expo 56 可能 OOM，建议使用 Node 22.13.1。

**Supabase 连接失败？** 检查 `.env` 中的 `EXPO_PUBLIC_SUPABASE_URL` 和 `EXPO_PUBLIC_SUPABASE_ANON_KEY`。

**教材知识改完为什么 App 里没变？** 教材浏览读构建时打入的 `ev1DisplayContracts` bundle。需先运行 `python scripts\orchestrator.py build-app-knowledge-bundle` 重新导出 `constants/ev1DisplayContracts.ts`，再重新构建 App。这与 Supabase `knowledge_nodes` 上传是两条独立路径，改云端数据不会自动更新本地 bundle。

**可以输入真实患者信息吗？** 不可以。MedLearn 明确禁止输入真实患者信息。
