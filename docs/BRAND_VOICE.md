# MedLearn Brand Voice

本文件是 MedLearn 品牌调性与文案语气的唯一权威来源。产品定位见 `docs/PROJECT_CONSTITUTION.md` 和 `docs/MVP_PRD_V2.md`，视觉设计语言见 `docs/DESIGN_CONTEXT.md`，学习行为原则见 `docs/LEARNING_DESIGN_PRINCIPLES.md`。

## 1. 品牌定位

MedLearn 是以结构化医学知识为基础的**临床思维训练系统**。

- **是**：教育系统、训练场、编辑式学习笔记、过渡期医师的克制工具。
- **不是**：临床决策支持、考试题库、游戏化学习、医学科普、患者教育。

书是基础。框架是核心。推理是终点。

## 2. 语气原则

### 克制

- 像编辑式学习笔记，不像营销文案。
- 不用感叹号制造兴奋，不用 emoji 装饰，不用"立即""马上""快来"催促。
- 用陈述句陈述事实，用祈使句给出下一步，不用修辞问句。

### 可信

- 只说能溯源的话。医学陈述必须有教材依据，不编造数据、统计、评价。
- 不确定时说"教材原文待确认"，不说"大概""可能""应该"。
- 数字带出处或页码，不带出处就不展示。

### 尊重

- 不羞辱低分、错误、中断或暂停。
- 反馈指向"这一个判断"，不指向"你这个人"。
- 早期笨拙是技能形成的预期，不是退步。

### 精确

- 反馈命名具体的差距，不说"再复习一下"。
- 下一步是可见的可执行动作，不是模糊建议。
- 一个高价值修正胜过一长串无差别的学习清单。

### 中立

- 不游戏化：没有金币、徽章、连胜、爆炸特效。
- 不情绪化：不鼓吹"加油""你最棒""再努力一点"。
- 不施压：完成下限后即可停止，不制造"错过就亏了"的焦虑。

## 3. 文案案例

### 首页

```
今日下限       ← 标签，陈述事实
完成今日下限    ← 按钮，明确动作
今日已完成      ← 完成态，不夸奖
再练一个        ← 可选动作，不施压
```

### 反馈

```
正确：本次判断与教材要点一致。        ← 指向判断，不指向人
错误：此处与教材"X"不符，关键差距是…  ← 命名差距
安全风险：这是需要优先修正的判断。     ← 安全优先，不羞辱
薄弱点：建议针对"X"做一次定向重试。   ← 可执行动作
```

### 病例

```
完成查体后可开检查，或提交诊断。     ← 指引下一步，不催促
查看检查结果后，可提交诊断。         ← 陈述可见选项
提交诊断          ← 按钮标签，明确动作
```

### 知识

```
学习问答 · 01      ← 自然编号，不全大写
临床判断 · 03      ← 自然文案，不用 "CLINICAL 03"
查看教材原文       ← 按需展开，不默认全显
本节要点           ← 编辑式标题，不装饰
```

### 错误与空态

```
知识地图暂时不可用        ← 陈述问题，不甩锅
本章小节暂时无法读取      ← 陈述状态，不编造
内容尚未接入              ← 诚实说明，不用"敬请期待"
请从知识地图选择科目      ← 指引动作，不说"你还没选"
```

## 4. 禁忌词

| 禁用 | 原因 | 替代 |
|---|---|---|
| 加油 / 你最棒 / 厉害 | 情绪化空话 | （删除，或陈述事实） |
| 立即 / 马上 / 快来 | 催促施压 | （删除，让用户自主） |
| 敬请期待 / coming soon | 空头承诺 | "内容尚未接入" |
| 大概 / 可能 / 应该 | 模糊医学陈述 | "教材原文待确认" |
| 金币 / 徽章 / 连胜 | 游戏化术语 | （删除） |
| 轻松掌握 / 一学就会 | 营销话术 | （删除） |
| 你还不知道 / 你忘了 | 羞辱性措辞 | "此处与教材不符" |
| 100% / 完美 / 零失误 | 绝对化表述 | 陈述具体分数或事实 |

## 5. 反馈语气细则

### 评分反馈

- 分数定位问题，不定义学习者。
- 先说具体差距，再说修正方向，不说"继续努力"。
- 安全关键错误（如禁忌症、致命误诊）优先于普通分数排序。
- 不展示排名、百分位、与他人比较。

### 错题与重试

- 重试是"针对 X 的定向重试"，不是"再做一遍"。
- 命名最高价值的一个修正点，不堆砌所有错误。
- 完成重试后更新该点状态，不累积"待办清单"焦虑。

### 空态与加载

- 加载态陈述正在做什么："正在读取本章小节"。
- 空态陈述事实 + 指引动作："从知识地图粘贴错题…保存后会出现在这里"。
- 错误态陈述问题 + 可重试："暂时无法读取" + 重试按钮。

## 6. 数字与数据呈现

- 用 serif-600 字号样式（`Typography.numberXL/Large/Medium`），不用粗体。
- 数字带单位或语境，不裸露："3/5 已掌握"、"p.77-98"。
- 掌握度用 `getMasteryColor` 取色 + 等级词（精通/良好/一般/薄弱/未掌握），不用红绿表情。
- 不编造进度、评分、统计、用户数据。

## 7. 学习边界声明

凡涉及 AI 问答、病例训练等场景，显式声明：

> 用于学习与复习，不替代临床判断或专业医疗建议。

声明要克制、可见、不抢戏。放在 Hero 下方或输入域附近，不用弹窗打断。

## 8. 文档与公共站点

- 公共文档站 `site/` 的文案同样遵守本规范。
- 不写营销文案，不夸大功能，不承诺未实现的特性。
- 描述行为时以 app 代码为准，不臆造。
