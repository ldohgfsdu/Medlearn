# Obsidian 项目知识库

MedLearn 的 Obsidian 项目知识库独立于 Git 仓库，用于跨会话笔记、ADR 草稿和管线复盘。

**路径：** `F:\MedLearn Vault`

## 与 F:\ml 的关系

| 位置 | 角色 |
|---|---|
| `F:\ml\docs\` | 权威、可提交的工程文档 |
| `F:\MedLearn Vault\` | 工作笔记、探索性草稿、验收记录 |
| `C:\Users\M1racle\Documents\Obsidian Vault\` | 私人笔记（不纳入项目） |

权威执行状态以 `F:\ml\state\*.yaml` 和 `F:\ml\docs\CURRENT_STATE.md` 为准，Obsidian 笔记不作为生产事实来源。

## 入口

Obsidian 中打开 `F:\MedLearn Vault`，首页见 `Medlearn/首页.md`。
