# App Integration Gate

Use when data, services, routes, or UI behavior enters the app.

- [ ] The source service returns expected production-shaped data.
- [ ] TypeScript types match database and service contracts.
- [ ] Loading, error, empty, partial, unavailable, and retry states are handled.
- [ ] Route parameters use canonical IDs and existing route builders.
- [ ] Catalog, content identity, and detail identity are not conflated.
- [ ] Only available disease nodes open complete disease details.
- [ ] Aspect-intent navigation safely falls back to the detail top.
- [ ] Evidence expands on demand and displays its page reference.
- [ ] Client code cannot read protected answers, rubrics, or review fields.
- [ ] Touch targets are at least 44 px and body copy remains readable.
- [ ] Relevant unit and route-contract tests pass.
- [ ] A runtime walkthrough covers the changed primary path.
